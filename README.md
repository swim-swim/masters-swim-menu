# Masters Swim Menu｜マスターズ水泳 練習メニュー作成

レベル・目的・トレーニング期・時間を選ぶだけで、サークル付きのマスターズ水泳練習メニューを自動作成する無料Webアプリです。登録不要・ブラウザだけで動きます。

**▶ アプリを開く: https://swim-swim.github.io/masters-swim-menu/**

## できること
- 条件（泳力レベル／トレーニング期／目的／総距離／予定時刻）からメニューを自動生成
- セットごとの開始・終了時刻、サークル、レストを自動計算。各項目は自由に編集可能
- 文字・数字をタップしてその場で編集、歯車アイコンで項目を一括編集、登録パターンから詳細・種目を選択
- 練習項目・パートのロック（再生成しても変わらない）
- クラブを複数登録し、開講クラス（ワンタップで条件切替）・大会（最大8件）・保存メニューを「クラブ管理」で一括管理
- メニュー表示：日本語／English／中文、フォント切替、全画面表示、画面ロック（スリープ防止）、A4ぴったり印刷・PDF
- データの引継ぎ：バックアップファイル、またはLINE・メールで送れるテキスト

## AIモード（任意）
通常モードと内蔵辞書翻訳はAPIキー不要で無料です。AIによるメニュー生成・翻訳を使う場合は、各自のAPIキー（Google Gemini／ChatGPT（OpenAI）／Claude（Anthropic）／Microsoft Azure OpenAI のいずれか）を「？ → AIキー設定」に入力してください。キーはその端末のブラウザにだけ保存され、選んだAIサービス以外には送信されません。バックアップや引継ぎテキストにも含まれません。

## データについて
入力したデータはすべて利用者のブラウザ内（localStorage）に保存され、サーバーには送信されません。

## 開発メモ
`index.html` はReact・アイコン・CSSをすべて同梱した単一ファイルです。ソースは `source/` にあります。
